📋 خطة تحسين نموذج Category

الملف: src/modules/category/category.model.ts | عدد الأسطر الحالي: 20 | الحالة: يحتاج تحسينات كبيرة

🔍 ملخص المشاكل الحالية

  • يوجد دالة واحدة فقط (getCategories) — لا يوجد CRUD كامل
  • اسم الكلاس مكتوب بأحرف صغيرة (categoryModel) — يخالف قاعدة PascalCase
  • لا يوجد معالجة أخطاء (بدون try-catch)
  • البحث يستخدم contains وهو حساس لحالة الأحرف على بعض قواعد البيانات
  • لا يوجد بيانات ترقيم الصفحات (عدد الإجمالي، معلومات الصفحة)
  • لا يوجد تحقق من صحة المدخلات على كائن الفلتر
  • لا يوجد أمان أنواع — نوع الفلتر محدد داخل الدالة بدلاً من استخدام interface
  • لا يوجد دعم حذف ناعم (soft delete)
  • لا يوجد دعم الترتيب والتصنيف
  • لا يوجد اختيار الحقول (select) أو تضمين العلاقات (include)

4. بحث غير حساس لحالة الأحرف خطأ

المشكلة

contains في Prisma حساس لحالة الأحرف على PostgreSQL و MySQL ببعض ترتيبات الأحرف (collation). البحث عن "electronics" لن يجد "Electronics".

الحل المقترح

// قبل where: { OR: [ { name: { contains: filter.search } }, { description: { contains: filter.search } }, ] } // بعد (غير حساس لحالة الأحرف) where: { OR: [ { name: { search: filter.search } }, { description: { search: filter.search } }, ] }

ملاحظة: search يتطلب فهرس @@@fulltext في MySQL أو يستخدم ILIKE في PostgreSQL. بدلاً من ذلك، يمكن استخدام { mode: 'insensitive' } مع contains إذا كنت تستخدم PostgreSQL.

5. إضافة بيانات ترقيم الصفحات تحسين

المشكلة

getCategories الحالية ترجع فقط مصفوفة التصنيفات. الـ controller يحسب total يدوياً باستخدام categories.length، وهذا خطأ — يجب أن يكون العدد الإجمالي المطابق للفلتر، وليس عدد العناصر المرتجعة.

الحل المقترح

async getCategories(filter: CategoryFilter): Promise<CategoryResult<Category>> { const where = this.buildWhereClause(filter); [const total, data] = await Promise.all([ prisma.category.count({ where }), prisma.category.findMany({ where, skip: filter.skip ?? 0, take: filter.take ?? 10, orderBy: filter.sortBy ? { [filter.sortBy]: filter.sortOrder ?? 'asc' } : { createdAt: 'desc' }, }), ]); return { data, total, page: filter.skip !== undefined ? Math.floor(filter.skip / (filter.take ?? 10)) + 1 : 1, limit: filter.take ?? 10, totalPages: Math.ceil(total / (filter.take ?? 10)), }; }

7. دعم الحذف الناعم تحسين

المشكلة

مخطط Prisma يحتوي على ishidden لكن النموذج الحالي لا يستخدمه لتصفية التصنيفات المخفية بشكل افتراضي.

الحل المقترح

private buildWhereClause(filter: CategoryFilter) { const where: Prisma.CategoryWhereInput = {}; // دائماً استبعاد التصنيفات المخفية ما لم يتم طلبها صراحة if (filter.isHidden === undefined || filter.isHidden === false) { where.ishidden = false; } // إضافة فلتر البحث if (filter.search) { where.OR = [ { name: { search: filter.search } }, { description: { search: filter.search } }, ]; } return where; }

8. إضافة الترتيب والتصنيف تحسين

المشكلة

لا يوجد طريقة لترتيب النتائج. النتائج تُرجع بترتيب غير متوقع.

الحل المقترح

// إضافة إلى واجهة CategoryFilter sortBy?: 'name' | 'createdAt' | 'updatedAt'; sortOrder?: 'asc' | 'desc'; // الاستخدام في findMany orderBy: { [filter.sortBy ?? 'createdAt']: filter.sortOrder ?? 'desc', }

10. التحقق من الاسم الفريد أمان

المشكلة

عند إنشاء تصنيف، لا يوجد تحقق من تكرار الأسماء قبل الوصول إلى قيد التفرد في قاعدة البيانات، مما يؤدي إلى أخطاء قاعدة بيانات خام.

الحل المقترح

async createCategory(data: { name: string; description: string; media?: any) { const existing = await prisma.category.findUnique({ where: { name: data.name }, }); if (existing) { throw new AppError(`التصنيف "${data.name}" موجود مسبقاً`, StatusCodes.CONFLICT); } return prisma.category.create({ data }); }

11. البنية النهائية المحسنة بنية

النموذج المحسن الكامل

import prisma from "../../config/database"; import AppError from "../../shared/errors/AppError"; import { StatusCodes } from "http-status-codes"; import { Prisma } from "@prisma/client"; export interface CategoryFilter { search?: string; skip?: number; take?: number; sortBy?: string; sortOrder?: 'asc' | 'desc'; isHidden?: boolean; } export interface CategoryResult<T> { data: T[]; total: number; page: number; limit: number; totalPages: number; } class CategoryModel { private buildWhereClause(filter: CategoryFilter): Prisma.CategoryWhereInput { const where: Prisma.CategoryWhereInput = {}; if (filter.isHidden === undefined || filter.isHidden === false) { where.ishidden = false; } if (filter.search) { where.OR = [ { name: { search: filter.search } }, { description: { search: filter.search } }, ]; } return where; } async getCategories(filter: CategoryFilter): Promise<CategoryResult<Prisma.CategoryGetPayload<{}>>> { try { const where = this.buildWhereClause(filter); const [total, data] = await Promise.all([ prisma.category.count({ where }), prisma.category.findMany({ where, skip: filter.skip ?? 0, take: filter.take ?? 10, orderBy: filter.sortBy ? { [filter.sortBy]: filter.sortOrder ?? 'asc' } : { createdAt: 'desc' }, }), ]); return { data, total, page: filter.skip !== undefined ? Math.floor(filter.skip / (filter.take ?? 10)) + 1 : 1, limit: filter.take ?? 10, totalPages: Math.ceil(total / (filter.take ?? 10)), }; } catch (error) { throw new AppError('فشل في جلب التصنيفات', StatusCodes.INTERNAL_SERVER_ERROR); } } async getCategoryById(id: string) { try { const category = await prisma.category.findUnique({ where: { id } }); if (!category) { throw new AppError('التصنيف غير موجود', StatusCodes.NOT_FOUND); } return category; } catch (error) { throw new AppError('فشل في جلب التصنيف', StatusCodes.INTERNAL_SERVER_ERROR); } } async createCategory(data: Prisma.CategoryCreateInput) { try { const existing = await prisma.category.findUnique({ where: { name: data.name } }); if (existing) { throw new AppError(`التصنيف "${data.name}" موجود مسبقاً`, StatusCodes.CONFLICT); } return prisma.category.create({ data }); } catch (error) { throw new AppError('فشل في إنشاء التصنيف', StatusCodes.INTERNAL_SERVER_ERROR); } } async updateCategory(id: string, data: Prisma.CategoryUpdateInput) { try { await this.getCategoryById(id); return prisma.category.update({ where: { id }, data }); } catch (error) { throw new AppError('فشل في تحديث التصنيف', StatusCodes.INTERNAL_SERVER_ERROR); } } async deleteCategory(id: string, soft = true) { try { if (soft) { return prisma.category.update({ where: { id }, data: { ishidden: true } }); } return prisma.category.delete({ where: { id } }); } catch (error) { throw new AppError('فشل في حذف التصنيف', StatusCodes.INTERNAL_SERVER_ERROR); } } } export const categoryModel = new CategoryModel();
