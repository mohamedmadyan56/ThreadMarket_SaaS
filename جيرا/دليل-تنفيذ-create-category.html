دليل تنفيذ Create Category — خطوة بخطوة

📘 اكتب كل ملف بيدك بالترتيب، وانسخ الكود من هنا

الفكرة: هنعمل موديول جديد اسمه category على نفس نمط باقي الموديولات (user / brand). كل ملف هتكتبه بيدك — الكود جاهز في الدليل ده. بعد كل خطوة خلّك مرتاح، ولو وقفت عند أي حاجة اسأل.

0. الأول: اتأكد إن السكيما جاهزة ✅

التعديل ده اتعمل سابقًا واترفع على البرانش. خد بالك من شكل الـ Category في prisma/schema.prisma:

model Category {
  id        String    @id @default(uuid()) @db.Uuid
  brandId   String    @map("brand_id") @db.Uuid
  name      String    @map("category_name")
  imageUrl  String?   @map("image_url")
  media     Json
  ishidden  Boolean   @default(false)
  Products  Product[]
  createdAt DateTime  @default(now())
  updateAt  DateTime  @default(now())
  brand Brand @relation(fields: [brandId], references: [id], onDelete: Cascade)

  @@unique([brandId, name])
  @@map("categories")
}
  • brandId — بيخزّن البراند صاحب القسم (المفتاح الأجنبي).
  • @@unique([brandId, name]) — الاسم فريد ضمن البراند بس.
  • media Json — حقل موجود قديمًا ومطلوب، فبنبعت له {} وقت الإنشاء.
  • لو مش متأكد إنه اتحفظ في الداتابيز، شغّل: npx prisma db push
✅ Commit بتاع الخطوة دي: التعديل ده اترفع سابقًا بالـ commit ده:
git commit -m "feat(category): add brand relation to category schema"
مفيش حاجة تعمله هنا — بس اتأكد إن البرانش بتاعك عليه (شغّل git log --oneline -3 واتأكد إنه موجود).

2. الخطوة الأولى — ملف الـ validators

ده بيستخدم zod للتحقق من المدخلات. بنلاقي الـ brandId جاي من الـ URL params، و name و imageUrl من الـ body. الميدلوير بتاع الـ validate في المشروع بيضيف params للـ body، فبيشتغلوا مع بعض في schema واحد.

src/modules/category/category.validators.ts
import { z } from "zod";

export const createCategorySchema = z.object({
    brandId: z.string().uuid({ message: "Invalid brand ID format" }),
    name: z.string().min(1, "Category name is required"),
    imageUrl: z.string().url("Invalid image URL format").optional(),
});
  • brandId — لازم يكون UUID صالح (قايمة من الرابط).
  • name — إجباري وأقل حاجة حرف واحد.
  • imageUrl — اختياري، ولو جاي لازم يكون URL صالح.
✅ Commit بتاع الخطوة دي: بعد ما تكتب الملف:

3. الخطوة التانية — ملف الـ model

ده اللي بيتكلم مع قاعدة البيانات (Prisma). قبل ما تعمل create، لازم تتأكد إن الاسم مش مكرر ضمن البراند — عشان نرمي خطأ 409 لو مكرر.

src/modules/category/category.model.ts
import prisma from "../../config/database";

class CategoryModel {
    async findByNameWithinBrand(brandId: string, name: string) {
        return prisma.category.findFirst({
            where: { brandId, name },
            select: { id: true },
        });
    }

    async create(brandId: string, name: string, imageUrl?: string) {
        return prisma.category.create({
            data: {
                brandId,
                name,
                media: {},
                ...(imageUrl ? { imageUrl } : {}),
            },
            select: { id: true },
        });
    }
}

export const categoryModel = new CategoryModel();
  • findByNameWithinBrand — يفحص لو قسم بنفس الاسم موجود عند نفس البراند.
  • create — ينشئ القسم ويرجّع id بس.
  • media: {} — الحقل المطلوب في السكيما، بنبعتله JSON فاضي.
  • ...(imageUrl ? { imageUrl } : {}) — لو imageUrl مش موجود، متضيفوش.
✅ Commit بتاع الخطوة دي: بعد ما تكتب الملف:
git add src/modules/category/category.model.ts git commit -m "feat(category): add category model create methods" git push

4. الخطوة التالتة — ملف الـ service

ده "منطق الأعمال" — الترتيب مهم هنا: الأول البراند موجود؟ وبعدين إنت صاحبه؟ وبعدين الاسم مش مكرر؟

src/modules/category/category.service.ts
import { categoryModel } from "./category.model";
import { brandModel } from "../brand/brand.model";
import AppError from "../../shared/errors/AppError";
import { StatusCodes } from "http-status-codes";

class CategoryService {
    async createCategory(brandId: string, userId: string, role: string, name: string, imageUrl?: string) {
        const brand = await brandModel.findBrandWithDocuments(brandId);
        if (!brand) {
            throw new AppError("Brand not found", StatusCodes.NOT_FOUND);
        }

        if (brand.userId !== userId && role !== "admin") {
            throw new AppError("You are not authorized to create categories for this brand", StatusCodes.FORBIDDEN);
        }

        const existing = await categoryModel.findByNameWithinBrand(brandId, name);
        if (existing) {
            throw new AppError("Category name already exists in this brand", StatusCodes.CONFLICT);
        }

        const category = await categoryModel.create(brandId, name, imageUrl);
        return { id: category.id };
    }
}

export const categoryService = new CategoryService();
الفحصلو فشلسبب
البراند موجود؟404 Not Foundالرابط فيه brandId مش موجود
صاحب البراند؟403 Forbiddenمينفعش أي حد يضيف قسم لبراند مش بتاعه
الاسم مكرر؟409 Conflictاسم القسم موجود عنده بالفعل
ملاحظة: brandModel.findBrandWithDocuments موجودة جاهزة في موديول الـ brand — بنعيد استخدامها بدل ما نكتب query تاني.
✅ Commit بتاع الخطوة دي: بعد ما تكتب الملف:

5. الخطوة الرابعة — ملف الـ controller

ده بياخد الـ request، بينادي الـ service، ويرجّع الرد. بيستخدم asyncHandler زي باقي المشروع عشان الأخطاء تتروح للـ error handler لوحدها.

src/modules/category/category.controller.ts
import { Request, Response } from "express";
import { categoryService } from "./category.service";
import { StatusCodes } from "http-status-codes";
import { asyncHandler } from "../../shared/utils/asyncHandler";
import AppError from "../../shared/errors/AppError";

export const createCategory = asyncHandler(async (req: Request, res: Response) => {
    const { brandId } = req.params as { brandId: string };
    const { name, imageUrl } = req.body as { name: string; imageUrl?: string };
    const user = (req as any).user;

    if (!user?.id) {
        throw new AppError("Not authenticated", StatusCodes.UNAUTHORIZED);
    }

    const result = await categoryService.createCategory(brandId, user.id, user.role, name, imageUrl);

    res.status(StatusCodes.CREATED).json({
        success: true,
        message: "Category created successfully",
        data: result,
    });
});
  • req.params.brandId — من الرابط.
  • (req as any).user — جاي من ميدلوير الـ authenticate (فيه id و role).
  • بيرجّع 201 مع data.id — زي ما التاسك طالب بالظبط.

6. الخطوة الخامسة — ملف الـ routes

بيمرر الطلب على الـ middlewares بالترتيب ثم الـ controller.

src/modules/category/category.routes.ts
import { Router } from "express";
import { validate } from "../../shared/middleware/validate";
import authenticate from "../../shared/middleware/authenticate";
import { authorize } from "../../shared/middleware/authorize";
import { createCategory } from "./category.controller";
import { createCategorySchema } from "./category.validators";

const router = Router();

router.post("/:brandId/categories",
    authenticate,
    authorize("brand"),
    validate(createCategorySchema),
    createCategory,
);

export default router;
⚠️ لاحظ إحنا كتبنا /:brandId/categories من غير /brands في الأول — لأن الـ router ده هيتركّب على /api/v1/brands في الخطوة الجاية، فالمجموع يبقى /api/v1/brands/:brandId/categories.
✅ Commit بتاع الخطوة دي: بعد ما تكتب الملف:
git add src/modules/category/category.routes.ts git commit -m "feat(category): add create category routes" git push

7. الخطوة السادسة — التركيب في server.ts

افتح src/server.ts وعمل تعديلين:

أولاً: ضيف السطر ده في الـ imports (بعد سطر الـ brandRouter):

import categoryRouter from "./modules/category/category.routes";

ثانيًا: ضيف السطر ده بعد سطر الـ brands (لأن الرابط كله بيبدأ بـ /brands):

app.use("/api/v1/brands", categoryRouter);

شكل الـ routes النهائي:

app.use("/api/v1/auth", authRouter);
app.use("/api/v1/brands", brandRouter);
app.use("/api/v1/users", usersRouter);
app.use("/api/v1/brands", categoryRouter);   // ← ضيف ده
خد بالك من نقطتين:
1. الـ mount على /api/v1/brands — مش /api/v1/categories — عشان الرابط الكامل يطلع مطابق للتاسك.
2. اتأكد إن مفيش userRouter مستورد مرتين في الـ imports (كان في نسخ قديمة مكرر).
