الخطأ الأول: خطأ في استيراد authenticate

الملف: src/modules/auth/auth.routes.ts:3

الكود الأصلي:

السبب: ملف authenticate.ts كان يصدر الدالة كـ export default authenticate، لكن auth.routes.ts كانت تحاول استيرادها كـ named import باستخدام { }.

الخطأ الثالث: ملف AppError يستخدم CommonJS

TS2306 — File 'AppError.ts' is not a module

الملف: src/shared/errors/AppError.ts

الكود الأصلي:

class AppError extends Error {
  constructor(message, statusCode) {
    super(message);
    this.statusCode = statusCode;
    this.status = `${statusCode}`.startsWith('4') ? 'fail' : 'error';
    this.isOperational = true;
    Error.captureStackTrace(this, this.constructor);
  }
}

module.exports = AppError;

السبب: الملف كان يستخدم module.exports (نظام CommonJS) بالرغم من أن الامتداد .ts والمشروع كاملًا يستخدم ES Modules (import/export). كما أن الأنواع (types) لم تكن معرفة.

الإصلاح

تم تحويل الملف إلى ES Module مع إضافة TypeScript type annotations:

class AppError extends Error {
  statusCode: number;
  status: string;
  isOperational: boolean;

  constructor(message: string, statusCode: number) {
    super(message);
    this.statusCode = statusCode;
    this.status = `${statusCode}`.startsWith('4') ? 'fail' : 'error';
    this.isOperational = true;
    Error.captureStackTrace(this, this.constructor);
  }
}

export default AppError;

الخطأ الخامس: اسم متغير خاطئ في auth.model.ts

TS2552 — Cannot find name 'failedLoginAttempts'. Did you mean 'failedAttempts'?

الملف: src/modules/auth/auth.model.ts:49

الكود الأصلي:

const failedAttempts = user.failedLoginAttempts + 1;
const updateData: any = { failedLoginAttempts };

السبب: في السطر 48، المتغير اسمه failedAttempts. في السطر 49، كان في shorthand { failedLoginAttempts } اللي بيبحث عن متغير بنفس الاسم — لكنه مش موجود لأن اسم المتغير مختلف.
