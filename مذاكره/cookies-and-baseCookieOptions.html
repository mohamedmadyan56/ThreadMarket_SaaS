شرح الـ Cookies و baseCookieOptions

الملف المشرح: src/modules/auth/auth.controller.ts

أولاً: إيه هي الـ Cookies؟

الكوكيز هي بيانات صغيرة (أقل من 4KB) مخزنة في المتصفح وبترسل تلقائيًا مع كل Request للـ Server. في مشاريع الـ SaaS بنستخدمها بشكل أساسي عشان نحافظ على حالة المستخدم (session management).

ثانياً: شرح baseCookieOptions

ده الـ object الموجود في auth.controller.ts:11:

const isProduction = ENV.NODE_ENV === 'production';

const baseCookieOptions = {
    httpOnly: true,
    secure: isProduction,
    sameSite: isProduction ? "none" : "lax" as "none" | "lax",
    path: "/",
}

1. httpOnly: true

أهم خاصية أمنية. بتمنع أي JavaScript (زي XSS attacks) من الوصول للكوكي. يعني لو في `<script>` حاقن في الموقع، مش هيقدر يقرا الـ refresh token بتاعك.

2. secure: isProduction

في الـ Production (NODE_ENV === 'production')، الكوكي مش هيتحط غير على HTTPS. في الـ Development بنستخدم HTTP عادي فبنخليها false.

3. sameSite: isProduction ? "none" : "lax"

تحكم في إرسال الكوكي عبر المواقع المختلفة (Cross-Site Request Forgery - CSRF).

  • lax (Development): الكوكي مش هيتبع non-safe requests من مواقع تانية (POST/PUT/DELETE).
  • none (Production): بيخللي الكوكي يتسلم عبر أي request حتى من مواقع تانية. ضروري عشان السيرفر والفرونت إند على domains مختلفة (CORS). لكن لازم يكون secure: true عشان sameSite: none يشتغل.

4. path: "/"

الكوكي متاح على كل مسارات الـ API مش route معين.

ثالثاً: إزاي هنستخدم الـ Cookies في المشروع؟

الـ auth controller حاليًا incomplete (17 سطر بس)، لكن الفكرة إن الـ baseCookieOptions هو الـ base لكل كوكي هنضيفه. الاستخدام المتوقع:

1. Set Refresh Token في Cookie (بعد Login)

res.cookie("refreshToken", refreshToken, baseCookieOptions)

بدل ما نرجعه في الـ Response Body (زي ما الـ service بيعمل دلوقتي)، بنحطه في كوكي httpOnly عشان نخفيه من الـ JavaScript Client.

2. Clear Cookie (بعد Logout)

res.clearCookie("refreshToken", baseCookieOptions)

3. Refresh Access Token

const refreshToken = req.cookies.refreshToken;

لما الـ access token يخلص، الـ frontend بيبعت request للـ /refresh والـ middleware بتقرا الـ refresh token من الـ cookie مباشرة.

رابعاً: الـ Tokens اللي عندنا في المشروع

Token مكان التخزين السبب
Access Token Response Body / Header (Authorization: Bearer) قصير العمر (دقايق) - بيستخدم في كل request عشان authentication. محتاج يتقرا من JS عشان يتضاف في الـ Header.
Refresh Token httpOnly Cookie طويل العمر (أيام/أسابيع) - بيستخدم بس عشان يجدد الـ access token. مخفي عن JS عشان أمان أعلى.
ملاحظة مهمة: sameSite: "none" بيحتاج secure: true. لو مش مستخدم HTTPS مش هتشتغل.

خامساً: ليه محتاج الـ Cookie مش LocalStorage؟

  • httpOnly: لو المستخدم عنده XSS في الموقع، المهاجم مش هيقدر يسرق الـ refresh token (لأنه مش accessible من JS).
  • Auto-send: الكوكيز بتتبعت تلقائيًا مع كل request، مش محتاج تديرها يدوي.
  • SameSite + CSRF protection: بيقلل هجمات CSFR بشكل كبير.
  • لو حطيت الـ tokens في localStorage، أي XSS يقدر يقراهم ويسرق الجلسة بالكامل.

سادساً: الـ Controller الكامل (auth.controller.ts)

الـ Controller هو طبقة التنسيق (Orchestration Layer) — بياخد البيانات من req، ينادي الـ Service، ويرجع الـ Response مع إدارة الـ Cookies.

مبدأ مهم: الـ Controller مافيهوش business logic خالص — كل logic في الـ Service. الـ Controller بس بيحول HTTP Request لـ Service Call ويرجع HTTP Response. 
import { Request, Response } from "express"
import { authService } from "./auth.service"
import { StatusCodes } from "http-status-codes";
import { asyncHandler } from "../../shared/utils/asyncHandler";
import AppError from "../../shared/errors/AppError";
import { ENV } from "../../config/env";

const isProduction = ENV.NODE_ENV === 'production';

const baseCookieOptions = {
    httpOnly: true,
    secure: isProduction,
    sameSite: isProduction ? "none" : "lax" as "none" | "lax",
    path: "/",
}

export const register = asyncHandler(async (req: Request, res: Response) => {
    const { username, email, password } = req.body;
    const filePath = req.file?.path;
    const result = await authService.register(username, email, password, filePath);
    res.status(StatusCodes.CREATED).json({
        success: true,
        message: "OTP sent to email. Please verify to complete registration.",
        data: result,
    });
})

export const verifyRegisterOtp = asyncHandler(async (req: Request, res: Response) => {
    const { token, otp } = req.body;
    await authService.verifyRegisterOtp(token, otp);
    res.status(StatusCodes.OK).json({
        success: true,
        message: "Email verified successfully. You can now login.",
    });
})

export const login = asyncHandler(async (req: Request, res: Response) => {
    const { identifier, password } = req.body;
    const result = await authService.login(identifier, password);
    res.cookie("refreshToken", result.refreshToken, {
        ...baseCookieOptions,
        maxAge: Number(ENV.REFRESH_TOKEN_EXPIRY) * 1000,
    });
    res.status(StatusCodes.OK).json({
        success: true,
        message: "Login successful",
        data: {
            accessToken: result.accessToken,
            accessTokenExpiration: result.accessTokenExpiration,
            user: result.user,
        },
    });
})

export const logout = asyncHandler(async (req: Request, res: Response) => {
    const refreshToken = req.cookies?.refreshToken;
    const accessToken = req.headers.authorization?.split(" ")[1];
    await authService.logout(refreshToken, accessToken);
    res.clearCookie("refreshToken", baseCookieOptions);
    res.status(StatusCodes.OK).json({
        success: true,
        message: "Logged out successfully",
    });
})

export const sendOtp = asyncHandler(async (req: Request, res: Response) => {
    const { email, purpose } = req.body;
    const result = await authService.sendOtp(email, purpose);
    res.status(StatusCodes.OK).json({
        success: true,
        message: "OTP sent to email",
        data: result,
    });
})

export const verifyOtp = asyncHandler(async (req: Request, res: Response) => {
    const { token, otp } = req.body;
    const result = await authService.verifyOtp(token, otp);
    res.status(StatusCodes.OK).json({
        success: true,
        message: "OTP verified successfully",
        data: result,
    });
})

export const resetPassword = asyncHandler(async (req: Request, res: Response) => {
    const { token, newPassword } = req.body;
    await authService.resetPassword(token, newPassword);
    res.status(StatusCodes.OK).json({
        success: true,
        message: "Password reset successfully",
    });
})

export const refreshAccessToken = asyncHandler(async (req: Request, res: Response) => {
    const incomingRefreshToken = req.cookies?.refreshToken;
    if (!incomingRefreshToken) {
        throw new AppError("No refresh token provided", StatusCodes.UNAUTHORIZED);
    }
    const result = await authService.refreshAccessToken(incomingRefreshToken);
    res.cookie("refreshToken", result.refreshToken, {
        ...baseCookieOptions,
        maxAge: Number(ENV.REFRESH_TOKEN_EXPIRY) * 1000,
    });
    res.status(StatusCodes.OK).json({
        success: true,
        message: "Access token refreshed",
        data: {
            accessToken: result.accessToken,
            accessTokenExpiration: result.accessTokenExpiration,
        },
    });
})
